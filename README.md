O PokeTrainn é um projeto desenvolvido com o objetivo de aprimorar conhecimentos em consumo de APIs RESTful e JavaScript.

Inspirado na jornada de um Treinador Pokémon, este projeto transforma a construção de uma equipe em um **desafio de sorteio gamificado**.

O Desafio:
Ao invés de escolher, o treinador tem sua equipe sorteada (incluindo a chance de *Shiny*), simulando a imprevisibilidade de uma jornada Pokémon real onde é preciso "caçar" e treinar o time que o destino lhe deu.

Funcionalidades

* **Sorteio Aleatório de Pokémon:** Faz requisições à PokeAPI para obter dados de Pokémon aleatórios.
* **Seleção de Gênero:** Permite ao usuário escolher um avatar (Ash/Menina).
* **Seleção de Geração:** Filtra os Pokémon sorteáveis por diferentes gerações.
* **Controle de Equipe:** O usuário pode sortear até 6 Pokémon para formar seu time.
* **Sorteio de Shiny:** Implementação de uma chance baixa de sortear a versão Shiny do Pokémon, um desafio extra para o Treinador!
* **Reset de Equipe:** Opção para limpar o time atual e começar um novo desafio.

Tecnologias Utilizadas:

* **HTML5** 
* **CSS3** 
* **JavaScript**
* **PokeAPI** 
* **PHP** 

Como Rodar o Projeto:

1.  **Clone o Repositório:**
    ```bash
    git clone https://github.com/bryoliveiira/poketrainn
    ```
2.  **Entre na Pasta do Projeto:**
    ```bash
    cd PokeTrainn
    ```
3.  **Abra no Navegador:**
    Abra o arquivo `index.html` diretamente no seu navegador. Recomendo usar a extensão **Live Server** do VS Code para evitar problemas.
